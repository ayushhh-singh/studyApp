## Brief: serious daily tool for UP civil-services aspirants, mostly budget Android, Hindi-first. Not a generic SaaS dashboard.
## Brand (2026-08-12 refresh — tree of knowledge, navy/blue/gold). Source of truth: `docs/design/reference-{1,2,3}.png`, committed. reference-2's labelled COLOR PALETTE panel is canonical for light; reference-3's DARK THEME swatches for dark. The logo is a supplied RASTER (`apps/web/scripts/assets/brand-mark-source.png`, 1254px) — never redraw it as a vector, and never re-shape it: it is drawn on a rounded SQUARE plate, so circle-masking clips its corners (tried and reverted, see `scripts/generate-pwa-icons.mjs`).
## Signature element: "the Rubric Dial" — a 180° graduated arc gauge (tick marks + coral->marigold->tulsi band + scoreboard numeral centered/below). Reads like an exam-hall meter, not a fitness-ring. Used for avg score stats, the Answers (flagship) nav accent, and evaluation results. Component: `src/components/ui-x/score-gauge.tsx`.
## Colors (CSS vars in src/index.css, both light+dark defined). Light is the default mode — dark only activates on explicit user toggle (src/stores/theme-store.ts), never from OS preference:
- `--background`/`--foreground` — light: #F7F9FC / #0B1D3B (navy ink). dark: #061225 / #E8EDF5. `--card` light #FFFFFF, dark #102542. NOT cream, NOT pure black/gray.
- `--action` / `--action-foreground` — **the only theme-INVERTING token**: the filled primary-action surface. light #0B1D3B (navy) on white text; dark #F7C873 (gold) on navy text. The reference deliberately flips it because navy on a navy page is invisible. Button `variant="default"`, active chips, progress fill and the underline-tab bar all use it.
- `--primary` (interactive blue) — light #1E4FD9, dark #6E9BFF (the literal brand blue measures 2.4:1 on the dark card). Links, active states, tints, focus ring. NOT the primary button — that is `--action`.
- `--marigold` — **#F7C873 in BOTH themes** (the brand gold; one value throughout the reference). Accent: streak flame, flagship highlight, the gold nav active rule, gauge high/mid band, `variant="secondary"` buttons.
- `--tulsi` — light: #10B981 / dark: #34D399. Success / correct / gauge top band.
- `--coral` — light: #F43F5E / dark: #FB7185. Gauge low band. For count pills and error fills prefer `--destructive` (#DA3125 light / #F2685C dark), the reference's own red — white on `--coral` is only 3.7:1.
- `--brand-navy` / `--brand-blue` / `--brand-gold` — the literal brand values, identical in both themes. Use these when the value must NOT flip: the logo, marketing panels that are navy by design, and **text on solid gold, which is always `--brand-navy` (10.9:1) — never white (1.6:1) and never `--marigold-foreground`, which flips light in dark and lands at 1.2:1.**
- Each of marigold/tulsi/coral has a paired `-foreground` token (a dark shade in light mode, a light shade in dark mode) for text sitting on that color's `/15` tint — **always use the pair together, never the raw token as a text or icon colour.** `text-marigold` on a light card is 1.6:1, `text-tulsi` 2.5:1. This is the single most-repeated defect in this codebase; it has been fixed app-wide three times.
## Fonts: Poppins headings (`--font-heading`, applied to h1-h6 at the base layer, LATIN SUBSET ONLY) + Inter body (`--font-sans`) + Noto Sans Devanagari (line-height >=1.75 always — it's the star, not a fallback). Poppins ships a Devanagari subset that is deliberately NOT imported, so Hindi headings fall through to Noto glyph-by-glyph. Display/"scoreboard" numerals (streak count, score %, big stats): `.font-display` = Inter weight 800, tabular-nums, tracking -0.02em — it beats the h1-h6 rule because it is unlayered, so `<h1 class="font-display">` correctly stays Inter. Poppins has no tabular figures; never route counting digits through it.
## Component primitives (build on these, don't hand-roll a fifth chip): `ui/button.tsx` (default/secondary/outline/ghost/destructive/link), `ui/tabs.tsx` (`variant="pill"` default, `variant="underline"` for the reference's bar-under-active look), `ui-x/chip.tsx`, `ui-x/badge.tsx` (new/hot), `ui-x/progress-bar.tsx`, `ui-x/info-card.tsx`, `ui-x/section-card.tsx`, `ui-x/progress-ring.tsx`.
## Spacing: strict 4px grid (Tailwind default scale — no arbitrary px values that break it).
## Radii: base `--radius: 0.75rem` (12px) for cards/inputs, 10px buttons. Pills for chips/badges. Gauge is a true arc, never radius-based.
## Layout: ONE nav config array (`src/lib/nav.ts`) drives both desktop sidebar and mobile bottom tab bar (<768px: 4 items + "More" sheet = 5 tabs). Flagship (Answers) always gets the gauge/gold accent, never a plain icon. The ACTIVE marker is a **gold rule** on the chrome's own edge (vertical in the sidebar, top edge in the bottom bar) plus a bolder label — never gold TEXT, and never colour alone. Brand mark: sidebar at md+, top bar below md (they occupy the same header band, so showing both duplicates it).
## The top bar is at capacity. Before adding anything to it, measure: at 320px the page title has a ~8-character floor and adding two elements collapsed it to 0px. Language and theme live in the account menu below `sm` for exactly this reason.
## Quality floor (non-negotiable): visible focus rings, `prefers-reduced-motion` respected, tap targets >=44px (header icon controls are the documented 36px exception), AA contrast in light AND dark, Devanagari line-height >=1.75.
## Verifying contrast: resolve colours through a `<canvas>`, never by parsing the computed CSS string — Tailwind v4 emits `oklab(L a b / alpha)` for every opacity-modified colour and a `/[\d.]+/g` parse silently drops the minus signs on the a/b channels, turning pale tints into near-black and inventing failures.
## NEVER: cream bg + serif + terracotta accent; near-black + single acid-green; broadsheet hairline-rule newspaper look; stock shadcn neutral gray (oklch 0/0/0 grays) — always route through the named tokens above.
